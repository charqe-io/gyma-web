# gyma-web

Bu repo, [gyma.charqe.io](https://gyma.charqe.io) adresinde yayınlanan GymA tanıtım
sitesinin **derlenmiş statik çıktısını** içerir.

Kaynak kod `charqe-io/gyma` (private) monoreposunda `apps/web` altındadır.
Buraya elle commit atmayın — her deploy'da GitHub Actions (`Deploy Web` workflow'u)
tarafından üzerine yazılır.
